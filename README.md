# 🏛️ LifeCraft — Atomic Discipline & Productivity PWA

**LifeCraft** is an offline-first Progressive Web Application (PWA) built around the philosophy of *Atomic Habits* and the *12-Week Year*. Designed to act as a strict, high-focus mirror of your daily actions, it bridges the gap between micro-habits, weekly execution, and long-term personal mastery.

---

## ✨ Core Features

* **⏱️ Flexible Focus Timer (1–240 Min):** Custom session durations with mandatory focus goals to eliminate aimless work.
* **📅 12-Week Weekly Planning & Vision Board:** Define your overarching weekly vision, break it down across a 7-day interactive grid, and track real-time completion rates.
* **⚖️ Accountability & Legal Habit Contract:** A strict commitment mechanism that enforces self-discipline and requires active acknowledgment when slipping off track.
* **🧬 Habit Framework & Achievement Log:** Pre-built and custom habit cards paired with a visual discipline network and permanent achievement history.
* **🌐 Dynamic Bilingual Interface (AR / EN):** Instant switching between Arabic (RTL) and English (LTR), including localized habit descriptions and language badges.
* **📴 Offline-First PWA:** Installable on desktop and mobile devices with Service Worker caching for uninterrupted offline usage.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Dark Theme & Responsive Grid), Vanilla JavaScript (ES6+)
* **Architecture:** Progressive Web App (`manifest.json` + `sw.js` Service Worker)
* **Storage:** Client-side persistence via `localStorage` with automatic schema migration
